# 配音手冊

這份手冊記錄我們怎麼合作做 AI 配音：誰負責什麼、聽到問題怎麼說、每支影片怎麼做。過程和測試數據記在 [`ai-voiceover-notes.md`](ai-voiceover-notes.md)，工具用法記在 [`../voiceover/README.md`](../voiceover/README.md)。

## 分工

| 你負責 | Claude 負責 |
|---|---|
| 用耳朵聽，說出感覺 | 把感覺對應到原因，決定怎麼改 |
| 決定稿子的內容和口氣 | 把稿子整理成配音稿、處理數字和讀音 |
| 最後聽一遍再發布 | 生成配音、自動檢查、用語音轉文字核對 |

Claude 聽不到聲音，只能量數字（語速、停頓、音高、音量）和核對文字。**像不像真人、好不好聽，永遠以你的耳朵為準。**

## 聽到問題怎麼說

不用懂術語。說出「在哪裡」和「什麼感覺」就夠了，下面是常見的感覺和對應的處理方式。

| 你的感覺 | 通常的原因 | 怎麼處理 |
|---|---|---|
| 像播音、像念稿、像講故事 | 稿子是書面短句；或聲音是用文字設計出來的 | 稿子改成聊天的說法；用真人錄音做的聲音 |
| 太慢、拖拉、不乾脆 | 聲音本身的說話速度；句子太碎 | 換說話快的聲音；短句接成長句（v4 沒有語速設定） |
| 某個字拖很長 | 「啊，」「呢，」這類語氣詞加逗號 | 減少語氣詞，不是每句都加 |
| 這句太強調、太戲劇化 | 前面有鋪陳的問句（「你猜多少？」） | 改成平實的說法 |
| 這句有氣無力、太平 | 這一段的語氣沒有指定 | 在這一段開頭加短的語氣標籤，例如 `[Curious, energetic, brisk pace]` |
| 整支都有氣無力、節奏平 | 語氣標籤寫了 relaxed、lower voice；或聲音是用平淡的示範做的 | 語氣標籤改成 `Confident, energetic, brisk pace`；用有精神的示範重做一版聲音 |
| 整體太平、沒起伏 | 穩定度太高；或經過變聲 | 降低穩定度；少一層處理 |
| 聲音悶、不透 | 中低頻太多、清晰度不夠 | 做聲音時用清楚的示範錄音；必要時輕微調音色 |
| 聲音太沉 | 聲音的音調低、低頻厚 | 語氣標籤或換聲音版本；必要時減少低頻 |
| 聲音太高、太興奮 | 語氣標籤寫了 upbeat、excited | 改成 relaxed、confident、lower voice |
| 有沙沙的氣泡音 | 聲音本身低沉 | 換較輕的聲音版本 |
| 某個詞念得含糊、像外語 | AI 把中文詞誤判成別的語言；引號干擾 | 指定語言 `--language zh`；配音時拿掉引號 |
| 字讀錯、聲調不對 | 多音字、數字、縮寫 | 在讀音修正表寫上要念的寫法 |
| 多念了一句、重複 | 語氣標籤太長 | 標籤保持很短；工具會自動檢查並重念 |
| 偏柔、有電音 | 女聲變男聲 | 不做跨性別變聲 |

## 每支影片的流程

1. **你給稿子**（Word 檔或文字）。
2. **Claude 整理成聊天版配音稿**：標題和原聲不念；書面短句改成口語；幾句合成一段；數字寫好讀法；原聲的位置留空白。事實和數字不動，並逐段核對。
3. **你審稿**：直接在 Word 檔上改，或說哪幾句要改。
4. **生成配音**：用固定的頻道聲音設定（`voiceover/channel-voice.args`）。每段念完自動檢查有沒有多念。
5. **核對**：整支用語音轉文字跟稿子比對，可疑的地方單獨再查。
6. **你聽**：說出有問題的時間點和感覺。
7. **修改**：只重念有問題的段落，其他不動。
8. **交付**：配音 MP3、字幕 SRT、配音稿。

## 已經確定的做法

**聲音**
- 模型用 ElevenLabs `eleven_v4`。它只有穩定度和相似度兩個設定，沒有語速和風格。
- v4 最適合真人錄音做的聲音，會照錄音的音色、語速和說話方式來講。用文字設計出來的聲音表現力較差。
- 頻道聲音是自有的：Arthur 示範 → 變聲成自己的音色 → 即時複製。它不會越用越好；要改進就用新的示範錄音做新版本（1～2 分鐘、風格一致）。
- 不複製別人的聲音。聲音庫的聲音可以直接使用，但不能拿來做成自己的。

**稿子**
- 稿子的寫法決定念法。聊天的說法（你想、說白了、對吧）才會念得像聊天。
- 語氣詞不要每句都加，「啊」全片留兩三個就好。
- 鋪陳的問句會讓下一句被念得很戲劇化，重要數字前面要小心。
- 帶引號的短語容易念含糊，配音時拿掉引號。

**語氣標籤**
- 整體語氣用幾個英文詞描述，目前是 `Confident, energetic, brisk pace`。寫 relaxed 或 lower voice 會讓整支沒精神。
- 標籤一定要短。超過一百個字元的標籤，會讓 AI 在八次裡多念七次。
- 個別段落要不同語氣時，在那一段開頭寫自己的短標籤。

**後製**
- 越少越好。不剪停頓、不整體加速，這些會讓聲音更不像人。
- 讀音和語氣的問題在生成時解決，不靠後製補救。
- 只做音量標準化（YouTube 約 -14 LUFS）。

## 還能進步的方向

- **重點段落多念幾次再挑**：AI 每次念的都不一樣。
- **每一段指定語氣**：吐槽、轉折、重點句各用不同的短標籤。
- **某一句怎麼改都念不好**：請 Arthur 或你本人示範那一句，再用變聲器換成頻道的聲音。
- **語速**：目前約每秒 4.3 個字，這是模型的上限。要更快，只能靠真人示範。
